# Devin OpenAI v0.2.0

Independent `devin-openai` provider for CLIProxyAPI v8.0.23. This community plugin adds manual browser PKCE authentication, per-account model discovery (including variant IDs), and daily/weekly Devin seat quota for session tokens. Inference uses CPA's native OpenAI-compatible executor.

## Installation

- Supported release platform: Linux amd64 with glibc 2.34 or newer (built with Go 1.25.1 on Debian 12); not musl-only/Alpine.
- Download `devin-openai_0.2.0_linux_amd64.zip` and `checksums.txt`, then verify with `sha256sum -c checksums.txt`.
- The archive root contains `devin-openai.so`, `LICENSE`, and `THIRD_PARTY_NOTICES.md`.
- Install using a CPA build with dynamic plugin support. Existing built-in `devin` accounts remain separate; do not change their provider type.
- The release follows the official CPA plugin-store asset contract. Store discoverability requires the registry contribution to be merged.

See the [README](https://github.com/PomoAi-ai/cliproxyapi-plugin-devin-openai#readme) for configuration, credential import, login, and quota API details.

## Compatibility and limitations

- **AI Gateway permission is required.** A Devin subscription or available seat quota does not establish Gateway access. Our real-account model-discovery check returned HTTP 403 with an explicit missing AI Gateway permission message; real Gateway inference and client subagent end-to-end operation are not verified.
- Chat Completions and Claude Messages tool calls/results, SSE, explicit reasoning parameters, model suffixes, and quota parsing were verified against a real CPA v8.0.23 host with a loopback mock upstream. This is not a claim of complete native Anthropic compatibility: unsigned thinking history can be removed by CPA, and native Anthropic signatures are not generated.
- Responses translation has been checked in CPA source, but is not covered by the plugin's host integration checks. Native server tools and `/responses/compact` are outside the verified scope.
- Seat quota requires a `devin-session-token$...` credential. Service-key quota and quota reset are unsupported. Expired session tokens require signing in again; no refresh protocol is implemented.
- The optional [CPAMP v1.14.5 integration](https://github.com/PomoAi-ai/cliproxyapi-plugin-devin-openai/tree/main/integrations/cpamp) is separate from this binary. Installing the CPA plugin does not install the management-panel patch.
- Other operating systems and architectures are not included in this release.

## Validation

Local Go tests, race checks, and vet passed. The real-host mock integration passed 17 inference requests plus quota coverage, including account isolation, HTTP 403 propagation, tool round trips, reasoning and a zero-percent quota window. No tests run in release CI; CI builds and validates the distribution contract.
